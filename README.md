# Prisma — For the Curious

Prisma is an interactive digital experience built around creative collaboration, visual experimentation, and computational art.

The website combines cinematic scroll-driven visuals, WebGL, glassmorphism, smooth scrolling, and interactive 3D elements.

## ✨ Features

- Scroll-driven cinematic image sequence
- Smooth Lenis scrolling
- GSAP-style scroll reveal animations
- Interactive Three.js Prism Core
- WebGL Lattice environment
- Solstice dawn animation
- Animated loading screen
- Responsive glassmorphism UI
- Reduced-motion support

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Three.js
- GSAP
- Lenis
- WebGL
- GLSL Shaders
